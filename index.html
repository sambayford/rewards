Connect your family's Firebase project
Rewards syncs across every parent's device using your own free Firebase project — nobody else's data mixes with yours.
  1. Go to console.firebase.google.com and create a project (free tier is enough)
  2. In Build → Authentication, enable the Email/Password sign-in method
  3. In Build → Firestore Database, create a database (production mode is fine)
  4. In Firestore's Rules tab, paste this and click Publish:
    rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { match /{document=**} { allow read, write: if request.auth != null; } } }
  5. In Project settings → General, scroll to "Your apps", add a Web app, and copy the config values below
